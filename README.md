# Decentralized Voting Smart Contract

A blockchain-based voting smart contract built using Solidity.

## Features

* Candidate Registration
* Voter Registration
* Secure Voting System
* Voting Time Control
* Emergency Stop Voting
* Winner Announcement
* Duplicate Registration Prevention

## Smart Contract Concepts Used

* Structs
* Mappings
* Enums
* Modifiers
* Access Control
* Dynamic Arrays
* Require Statements

## Functions

### Candidate Functions

* registerCandidate()
* getCandidateList()

### Voter Functions

* registerVoter()
* getVoterList()
* castVote()

### Admin Functions

* setVotingPeriod()
* announceVotingResult()
* emergencyStopVoting()

## Tech Stack

* Solidity
* Remix IDE
* Ethereum
